# 十字军之王III Wiki 中文翻译项目

本项目将 [Crusader Kings III Wiki](https://ck3.paradoxwikis.com/) 的核心内容翻译为简体中文，方便中文玩家查阅游戏机制和攻略。

## 项目结构

```
Translation_CK3/
├── source/en/          # 英文原文（从wiki抓取）
├── translated/zh/      # 中文翻译
├── scripts/            # 抓取和辅助脚本
└── README.md
```
