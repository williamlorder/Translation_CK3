冒险者（Adventurer）是可游玩的无领地贵族角色（Character），他们携带追随者（Follower）和一座[营地（Camp）](https://ck3.paradoxwikis.com/Camp)周游世界，并拥有一套不同的[生活方式（Lifestyle）](https://ck3.paradoxwikis.com/Lifestyle)特长（Perk）。由于没有来自领地[头衔（Title）](https://ck3.paradoxwikis.com/Titles)的稳定收入，冒险者主要通过为有领地的统治者（Ruler）完成[契约（Contract）](#契约)来赚取 [] 金币（Gold），并且必须储备 [] [补给（Provisions）](https://ck3.paradoxwikis.com/Provisions)才能移动营地。冒险者可以随时指定继承人，而且对他们来说这是免费的。

统治者在战争期间可以随时雇佣冒险者作为[雇佣兵（Mercenary）](https://ck3.paradoxwikis.com/Mercenaries)。这需要花费30 [] 金币，以及在战争结束时根据冒险者贡献按比例支付的第二笔费用。除非统治者对冒险者拥有 [] 强弱点（Strong Hook），否则冒险者必须接受。统治者也可以选择将冒险者驱逐出自己的领地，这将阻止冒险者接受契约，并给予他们3个月的时间离开领地，否则可被逮捕。未能成功逮捕冒险者将导致战争。


## 成为冒险者


有多种方式可以作为冒险者进行游玩：

- 在三个起始日期中选择一个预设冒险者开始游戏

- 使用[统治者设计器](https://ck3.paradoxwikis.com/Ruler_Designer)创建自定义冒险者

- 在继承时使用[选择新命运](https://ck3.paradoxwikis.com/index.php?title=Choose_a_New_Destiny&action=edit&redlink=1)选择一个无领地角色

- 如果继承顺位较低的孩子请求成为冒险者，你可以切换为扮演他们

- 通过特定文化（Culture）/信仰（Faith）的决策（Decision）

- 失去所有领地头衔


如果统治者成为冒险者，他们将失去3级声望（Fame）。除了玩家以外，AI角色也可能成为冒险者；拥有"大胆的学徒"或"以剑为生"文化传统的角色，成为冒险者的概率会增加。拥有过量 [] 金币的流浪者也可能决定组建一个冒险者营地。


## 赞助者名录


冒险者拥有一份赞助者名录（Roll of Patrons），可在营地菜单中查看。家族成员、朋友、恋人以及冒险者完成常规契约的统治者，都会被加入赞助者名录。名录中的统治者可以被请求提供 * 补给、[] 金币、[] 骑士（Knight）、一支随机常备军（Men-at-Arms）团、一桩包办婚姻或另一份契约。*荣誉嘉宾*特长还允许请求举办一场冒险者作为荣誉嘉宾的 * 宴会，*坚定领袖*特长还允许向伯爵及以上等级的统治者请求举办 [](https://ck3.paradoxwikis.com/File:Activity_tournament.png) 大型锦标赛。请求将使统治者的 [] 好感度（Opinion）降低 **25**，持续10年。只有赞助者能够满足的请求才会出现，其接受概率会随着冒险者的声望等级提升而增加。


## 冒险者军队


冒险者没有可征召的征召兵（Levy），而是依赖常备军和骑士。他们不需要为常备军支付维护费，但常备军也不会随时间自动补充。通过*入乡随俗*生活方式特长，可以招募当前所在地文化的常备军。通过向赞助者请求获得的团将满编补充，且可以是其文化能够使用的任何常备军类型。

有以下几种替代方式来补充常备军：

- 当冒险者成功围攻一个领地（Holding）时，其常备军将根据该领地战利品的一半进行补充。

- 冒险者可以花费 [] 金币或 [] 补给手动补充常备军，或通过 [] 外交（Diplomacy）和 [] 勇武（Prowess）联合挑战来完成。

- 在拥有 [] 部落制或 [] 瓦努阿制政体的领地中，还可以每团每25名士兵花费75 [] 威望（Prestige）来补充。

- 在拥有 [] 教会制、[](https://ck3.paradoxwikis.com/File:Theocracy_government.png) 神权制或 [](https://ck3.paradoxwikis.com/File:Holy_order_government.png) 军事修会政体的领地中，还可以每团每25名士兵花费50 [] 虔诚（Piety）来补充。

- 如果冒险者拥有至少5 [] 恐惧（Dread），还可以每团每25名士兵花费5 [] 恐惧来补充。成功招募的概率为每点 [] 恐惧2%。


默认情况下，冒险者只能拥有2名 [] 骑士，但可以通过特定营地目的或"熊熊营火"建筑来增加数量。冒险者不能拥有荣誉封号（Accolade）。

拥有至少一个团的冒险者可以主动加入统治者的战争。如果战争结束时他们的战争贡献（War Contribution）足够，统治者将支付 [] 金币作为报酬。冒险者可以在非自己主导的战争中随时离开或更换阵营，但这将消耗2级声望和80 [] 压力（Stress），并且原先同盟的战争领袖将成为冒险者的宿敌。有领地的玩家统治者也可以从雇佣兵标签页中雇佣领地内的冒险者，但无法控制他们的军队（Army）。

## 采集补给


冒险者每3年可以尝试采集 [] 补给，方法是将鼠标悬停在营地上选择"采集补给"，或使用同名决策。冒险者可以使用 [] 学识或 [] 勇武来决定成功概率。如果冒险者拥有 [](https://ck3.paradoxwikis.com/File:Chief_forager_camp_officer.png) 首席觅食者或 [](https://ck3.paradoxwikis.com/File:Huntperson_camp_officer.png) 猎人军官，可以派遣他们前去，成功概率取决于该军官的能力。

如果使用 [] 学识且营地所在男爵领拥有 [](https://ck3.paradoxwikis.com/Farmlands) 农田、[](https://ck3.paradoxwikis.com/Floodplains) 泛滥平原、[](https://ck3.paradoxwikis.com/Oasis) 绿洲、[](https://ck3.paradoxwikis.com/Plains) 平原或 [](https://ck3.paradoxwikis.com/Wetlands) 湿地地形，失败时冒险者或军官有概率获得 [] 生病特质。如果角色已有该特质、男爵领为其他地形，或角色使用 [] 勇武，失败时角色将有概率受伤。

如果营地所在男爵领受到冬季影响，使用 [] 学识的成功概率将降低，且失败将给予角色一个 [] 健康惩罚，持续3年。

正统派仅在角色对一个 [] 王国头衔拥有 [] 法理宣称（Pressed Claim）时可用。

[](https://ck3.paradoxwikis.com/File:Camp_temperament.png)  [](https://ck3.paradoxwikis.com/File:Camp_temperament.png)坚定的营地士气

营地士气（Camp Temperament）由所有追随者的平均 [] 好感度决定。

- 如果追随者的平均 [] 好感度为 **40** 或以上，营地士气将为 [](https://ck3.paradoxwikis.com/File:Loyalty_selfless.png) 坚定，这将给予每级声望 **+0.4%** [] 契约计策（Scheme）进度和 **+5%** [] 坚韧度。如果冒险者拥有"绝对掌控"特长，还将每20 [] 恐惧获得相同加成。如果冒险者拥有"荣幸效力"特长，还将每名追随者获得相同加成，最多5名。如果冒险者拥有"营地学者"特长，还将每名拥有至少10 [] 学识的追随者获得相同加成。其他特长还可以提供不同的加成而非上限：
"威严"给予按比例的 [] 个人计策阶段时长加成

- "虔信"给予 **+5** [] 信仰敌对优势

- "宗教营地"给予每名同信仰追随者 **+0.4** [] 每月虔诚

- "多元之力"给予每3名不同信仰的追随者所有技能 **+1**

- 如果追随者的平均 [] 好感度为 **-40** 或以下，营地士气将为 [](https://ck3.paradoxwikis.com/File:Loyalty_self-interested.png) 哗变，这将给予每级声望 **+10天** [] 契约计策阶段时长和 **-10%** [] 伤害。

- 如果追随者的平均 [] 好感度在 **-39** 和 **39** 之间，营地士气将为 [](https://ck3.paradoxwikis.com/File:Loyalty_situational.png) 安抚，没有任何效果。


营地士气还会在各种事件中发挥作用。


## 契约


[](https://ck3.paradoxwikis.com/File:Tier_1_contract.png)  [](https://ck3.paradoxwikis.com/File:Tier_1_contract.png)一份契约

冒险者可以在世界地图上看到由统治者发布的契约。契约分为3个等级。大多数契约要求冒险者[旅行](https://ck3.paradoxwikis.com/Travel)到其男爵领才能接受。统治者只有在有余裕 [] 金币时才会发布契约。

- [] 男爵和 [] 伯爵提供1级契约

- [] 公爵提供2级契约，且仅面向 [] 显赫声望等级或以上的冒险者

- [] 国王提供3级契约，且仅面向 [] 万人敬仰声望等级或以上的冒险者

- [] 皇帝和宗教领袖提供3级契约，且仅面向 [] 传奇人物声望等级的冒险者

- [] 霸主不提供契约


[] 宿敌和交战中的统治者永远不会发布契约。可以通过使用"拜访领地"决策与城镇公告员交谈来创建额外契约。除非冒险者的文化拥有"撒哈拉游牧民"传统，否则契约不会出现在撒哈拉地区。

- +2 如果奉献等级为 [] 美德楷模或 [] 宗教偶像且委托者信仰相同

+4 如果角色在序幕事件中通过 [] 谋略或 [] 外交挑战，-1 如果挑战失败。
