# 囚犯

> 原文来源: https://ck3.paradoxwikis.com/Prisoners
> 授权协议: CC BY-SA 3.0 (Paradox Wikis)

本文已针对游戏PC[版本](https://ck3.paradoxwikis.com/CK3_Wiki:Versioning)（1.20）进行了校验。

  两名被囚禁的贵族
囚犯（Prisoner）是被强行扣留在他人宫廷中的角色（Character）。角色可以通过[绑架阴谋](https://ck3.paradoxwikis.com/Abduction_scheme)、在战争中占领角色的领国首都，或在战斗后敌方指挥官武力值（Prowess）较低时俘获囚犯。统治者可以尝试监禁（Imprisonment）其领国内的任何角色，但这会招致[暴政（Tyranny）](https://ck3.paradoxwikis.com/Tyranny)，尤其是当囚犯是贵族时，除非他们犯有罪行（Crime）。被囚禁的角色可以被释放、勒索赎金、施以酷刑或处决。

如果囚犯在某统治者主头衔（Title）的继承顺位中排名第三或更靠前，则在与该统治者的战争中将提供[战争分数](https://ck3.paradoxwikis.com/index.php?title=War_Score&action=edit&redlink=1)，但在此类战争结束时将被释放。

## 监禁效果

角色被监禁后，将被关押在地牢或软禁中，可以在两者之间自由转换。默认情况下，平民被关押在地牢中，贵族则被软禁。被监禁期间，他们会受到以下惩罚：

| | **软禁（House Arrest）** | **地牢（Dungeon）** |
| **外交（Diplomacy）** | **-5** | **-5** |
| **自然恐惧值（Natural Dread）** | **-20** | **-30** |
| **恐惧值流失（Dread Loss）** | **-100%** | **-100%** |
| **[[Focus invalid.png]](https://ck3.paradoxwikis.com/File:Focus_invalid.png) 每月生活方式经验** | **-75%** | **-150%** |
| **压力（Stress）增益** | **0** | **+50%** |
| **囚犯家属好感度（Opinion）** | **0** | **-15** |
| **健康惩罚** | **无** | **严重** |
| **疾病风险** | **无** | **5年后** |
| **逃脱几率** | **正常** | **降低** |

囚犯在监禁期间会积累压力（Stress），如果压力过高最终会导致死亡。

## 协商释放

统治者可以提出释放囚犯，作为交换要求以下一项或多项条件：

| **条件** | **接受度** | **好感度（持续10年）** | **要求** |
| 获得弱把柄（Weak Hook） | **-80** | **-20** | |
| 要求皈依 | **-20** | **-10** | 信仰不同；囚犯是你的封臣（Vassal）或非统治者；囚犯不是宗教领袖 |
| 驱逐（Banish） | **-50** | **-20** | 囚犯不是独立统治者；囚犯不是冒险者 |
| 招募 | **-10** | **-15** | 囚犯不是统治者；囚犯不是冒险者；囚犯不是廷臣 |
| 放弃宣称 | **-25** | **-30** | 囚犯对你拥有的某个头衔有宣称 |
| 出家修行 | **-30** | **-10** | 信仰相同；教派鼓励或接受修道制度；囚犯是家族成员；囚犯是廷臣 |

无条件释放囚犯会花费 **10** 恐惧值，并在10年内获得囚犯 **+20** 好感度。如果被释放角色的头衔等级足够高，无条件释放可能会获得正统性（Legitimacy）。

## 赎金

统治者可以赎回被囚禁的角色，以金币（Gold）或弱把柄（Weak Hook）交换囚犯的自由。*赎金*互动是对囚犯使用的，而非对接收方。收到赎金的角色按以下优先顺序决定：

- 如果囚犯有领地，则为囚犯本人

- 如果囚犯是廷臣，则为其直属领主（Liege）

- 如果囚犯没有领地，则为囚犯本人

囚犯及其直属领主也可以主动向看守者提出支付赎金，并可额外使用把柄（Hook）施压。由领主支付赎金赎回的封臣和廷臣将获得 **+5** 好感度，持续1年。

使用金币支付时，囚犯的赎金价格取决于赎金接收方的主头衔等级以及囚犯与接收方的关系。如果配偶同时也是第一继承人和/或近亲家族，则只适用配偶价格。如果赎金接收方无力支付全额赎金，价格将降低至其剩余的全部金币。如果看守者拥有*[黄金义务](https://ck3.paradoxwikis.com/Golden_Obligations)*能力，则所有赎金费用将增加至约为看守者税收收入的6倍（最低50金币，最高300金币）。无领地且无领主的角色，如果看守者拥有*黄金义务*能力（可进一步增加），或者该角色至少有100金币可支配，则赎金为100金币。

## 惩罚

惩罚角色可能会根据惩罚类型和囚犯的头衔等级获得恐惧值。

### 处决

处决被囚禁的角色会产生以下效果：与受害者家族（Dynasty）的 **-20** 好感度，与受害者领主的 **-25** 好感度，与受害者朋友和情人的 **-30** 好感度，与受害者家人和配偶的 **-50** 好感度，以及 **+2** 暴政，除非囚犯犯有极严重的罪行或信奉被视为敌对或邪恶的信仰。共有3种处决方式：

| **处决方式** | **虔诚（Piety）** | **要求** |
| **斩首** | - 平民：**-25**；- 贵族：**-100** | - [是] 相同信仰；- [否] 教派拥有"血腥祭典"核心教义 |
| **火刑** | 如果教派拥有原教旨主义教义：**+25** | - [否] 相同信仰；- [否] 教派拥有"血腥祭典"核心教义 |
| **献祭** | - 囚犯信仰相同：**+50**；- 囚犯信仰不同：**+250** | [是] 教派拥有"血腥祭典"核心教义 |

处决可以通过以下选项增强，这些选项会为其增加一些额外效果：

- 拥有食人者（Cannibal）特质（Trait）或将"仪式食人"作为核心或个人教义的角色可以选择吞噬囚犯，这将减少 **-35** 压力，但有20%的几率获得疾病（Ill）特质，并且如果角色尚未拥有食人者特质则会获得该特质。如果"仪式食人"是核心或个人教义，还会获得 **+3** 灵性满足感。

- 雇用了[[Executioner court position.png]](https://ck3.paradoxwikis.com/File:Executioner_court_position.png) 刽子手的统治者可以选择公开处决，这将在领国首都获得 **+15** 民众好感度，持续5年，并根据每个能力等级在所有直辖伯爵领增加 **+3** 控制力。

- 拥有"长猪"谋略（Intrigue）生活方式能力的冒险者可以选择将囚犯转化为随机数量的补给。

如果角色拥有皇家宫廷，并且具有反复无常、狡诈、冷酷、虐待狂或报复心特质，处决宿敌时有25%的几率获得将其头骨制成基座物品文物的选项。如果囚犯是死敌，则该选项必定出现。如果统治者没有雇用[[Executioner court position.png]](https://ck3.paradoxwikis.com/File:Executioner_court_position.png) 刽子手，将失去与御医或古物学家的 **-30** 好感度。

### 酷刑

对角色施以酷刑会产生以下效果：

- 施刑者失去 **-100** 虔诚，除非其教派拥有"苦痛升华"核心教义或拥有"神罚"能力

- 如果施刑者教派拥有"苦痛升华"核心教义，则获得 **+100** 虔诚

- 如果施刑者拥有虐待狂（Sadistic）特质，则减少 **-10** 压力

- 如果施刑者拥有轻信（Trusting）特质，则增加 **+10** 压力

- 如果施刑者拥有仁慈（Compassionate）特质，则增加 **+100** 压力

- 被施刑角色对施刑角色的好感度降低 **-75**，持续50年

- 被施刑角色获得"近期遭受酷刑"修正，持续5年，健康 **-0.75**

- 如果被施刑角色拥有或知道一个秘密，将有选项可以揭露秘密以避免酷刑

### 传统惩罚

以下惩罚仅在成年角色的文化拥有某些传统时可用：

- **阉割**适用于拥有阿姆哈拉高地人、宫廷宦官、拜占庭传统或宫廷政治传统的文化。如果囚犯年龄低于12岁，将获得无须宦官特质，否则将获得宦官特质。被阉割的角色有66%的几率受到严重的健康和压力惩罚，持续5年，除非该角色雇用了御医，在这种情况下几率根据能力等级从50%降低到15%。阉割会导致与囚犯的 **-50** 好感度，持续50年，以及与其近亲家人和配偶的 **-20** 好感度，持续20年。

- **致盲**适用于拥有拜占庭传统、仁慈致盲或宫廷政治传统的文化。囚犯会获得失明（Blind）特质。致盲会导致与囚犯的 **-50** 好感度，持续50年，以及与其近亲家人和配偶的 **-20** 好感度，持续20年。

- **致残**仅适用于二人执政体制中的角色，且会终结权力共享。可以选择给予囚犯失明、毁容、断腿或残疾特质。男性还可以被阉割。如果是共治皇帝执行，他们将夺取皇帝除家族贵族头衔外的所有头衔。

### 太阳审判

太阳审判是拥有"太阳崇拜"教义的信仰可以使用的惩罚，仅适用于犯有罪行的囚犯。角色将获得 100 虔诚。囚犯会死亡或幸存，如果幸存且与执行者信仰相同，将获得 **+3** 每月虔诚和 **+15** 同信仰好感度，持续15年。幸存几率取决于领国首都的地形和囚犯的健康状况。
