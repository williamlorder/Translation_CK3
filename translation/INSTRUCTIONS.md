# 翻译规范（给翻译 agent）

你在把《十字军之王III》社区维基（ck3.paradoxwikis.com，CC BY-SA 3.0 授权）的页面片段翻译成**简体中文**。网站会把译文按原页面结构回填，所以必须逐段、忠实、完整地翻译。

## 每个批次的流程
1. 读取 `work/batches/<批次ID>.json`。其中 `pages` 是这些片段所在的页面（提供上下文），`segments` 是 `{ "k": 键, "t": 英文原文 }` 列表。
2. 把每个 `t` 译成简体中文。
3. 用 Write 工具写入 `translation/tm/<批次ID>.json`，内容是一个 JSON 对象：`{ "键": "译文", ... }`，必须包含批次中的**每一个**键，不能多也不能少。
4. 运行 `node scripts/check_batch.js <批次ID>`，若有问题就修正并重写文件，直到输出 `OK`。
5. 不要修改其他任何文件。

## 占位符（最重要）
- 原文中的内联 HTML 已被替换为占位符：
  - 成对占位符，如 `<a1>…</a1>`（链接）、`<b2>…</b2>`（粗体）、`<i3>…</i3>`（斜体）、`<s4>…</s4>`（span）、`<sup5>…</sup5>`、`<x6>…</x6>`：**里面的文字要翻译**。
  - 自闭合占位符，如 `<img7/>`、`<br8/>`、`<c9/>`、`<a10/>`、`<s11/>`：代表图片、换行、代码等，**原样照抄**。
- 每个占位符在译文中出现的次数必须与原文完全相同，成对占位符必须正确嵌套；可以根据中文语序调整占位符的位置。
- 不要新增任何占位符或 HTML 标签，不要改动占位符的名字和数字。
- HTML 实体：`&lt;`、`&gt;` 必须保持原样；`&amp;` 可以保留或写成 `&`。

示例：
- 原文：`<a1>Traits</a1> can be gained or lost through <a2>events</a2>.`
  译文：`<a1>特质</a1>可以通过<a2>事件</a2>获得或失去。`
- 原文：`+2 <a1>Martial</a1><br2/>+3 <a3>Prowess</a3>`
  译文：`+2 <a1>军事</a1><br2/>+3 <a3>勇武</a3>`

## 翻译要求
- **忠实完整**：每一句都要翻译，不得省略、概括、增补解释，也不要附加英文注释（下面“成就”规则除外）。
- **术语**：必须遵守 `translation/glossary.md`。同一术语全篇统一。
- **数值与格式**：`+2`、`-10%`、`×2`、日期、年份、版本号保持不变。例如 `+10 Same Trait Opinion` → `+10 相同特质好感度`。
- **专有名词**：历史人物、地名、国家、王朝用通行中文译名（如 Charlemagne → 查理曼，Holy Roman Empire → 神圣罗马帝国）；生僻名字按新华社译名习惯音译。
- **标题与表头**：简洁的中文，如 `Cost` → `花费`，`Yes` → `是`，`No` → `否`，`Date` → `日期`。
- **决策/事件/互动名称**：要翻译，如 `Meditate in Seclusion decision` → `闭关冥想决策`。
- **成就名称**（成就页面）：写成 `中文译名（English Name）`，方便玩家与 Steam 对照。
- **不翻译**：控制台命令、脚本代码、模组字段名、文件路径、URL、品牌名（Paradox、Steam、YouTube）。`Crusader Kings III` 译为 `十字军之王III`。
- **标点**：中文句子使用全角标点（，。：；？！“”（）），数字与公式内部保持半角。
- 已经不是英文或只是品牌名的片段，原样保留。

## JSON 格式
- 必须是合法的 UTF-8 JSON：字符串里的 `"` 写成 `\"`，反斜杠写成 `\\`；中文引号优先使用 “ ”。
- 不要注释，不要尾逗号；键必须与批次中的 `k` 完全一致。
